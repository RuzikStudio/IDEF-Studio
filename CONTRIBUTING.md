# Участие в разработке

Для ошибки укажите версию приложения, Windows, шаги воспроизведения и ожидаемый результат. Прикладывайте только обезличенные примеры схем.

Для разработки нужен Node.js 24. Выполните `npm ci`, `npm test`, `npm run build`. Запуск собранного приложения: `npm start`. Сборка Windows: `npm run package`.

Изменения формата проектов должны сохранять чтение прежних файлов и сопровождаться проверками загрузки. Не добавляйте личные проекты, токены, зависимости node_modules и готовые сборки в Git.
