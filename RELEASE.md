# Выпуск на GitHub

1. Создайте репозиторий и загрузите содержимое подготовленной папки GitHub-ready. Не загружайте всю рабочую папку Codex.
2. Убедитесь, что Windows checks прошёл на GitHub. Включите Dependabot alerts, secret scanning/push protection и private vulnerability reporting, если доступны.
3. Проверьте название автора и контакт для проекта перед публичным выпуском.
4. Создайте тег v0.5.0 и предварительный Release. Укажите реализованные функции и ограничения из README.
5. Соберите через npm ci и npm run package. Упакуйте всю release/win-unpacked, сохраняя лицензии Electron/Chromium. Добавьте LICENSE и THIRD_PARTY_NOTICES.txt в архив.
6. Приложите ZIP приложения, соответствующий исходный код и SHA256. Код в теге должен точно соответствовать сборке. Не выдавайте прежние EXE за сборку из обновлённого исходного кода.

После публикации проверьте скачивание и запуск на чистой Windows. Подпись издателя и установщик пока отсутствуют.
