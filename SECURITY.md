# Сообщения об уязвимостях

Используйте приватное сообщение об уязвимости во вкладке Security репозитория, если владелец включил эту функцию. Не публикуйте токены, личные схемы и рабочие эксплойты в публичных Issues.

Проект находится в предварительной стадии. Исправления выпускаются для последней версии; гарантированный срок ответа пока не установлен.
